## What it does

`newprompt` keeps a record of Claude Code sessions. Each prompt gets its own dated directory holding the prompt, the plan, and the full conversation.

## Key features

- `newprompt --launch <topic>` creates the directory, opens your editor for the prompt, and launches Claude Code
- When the session ends, the chat history is copied into the prompt directory, along with a human-readable Markdown version
- A manual workflow for sessions that are already open: create the directory first, then save the chat afterwards with `--save-chat`
