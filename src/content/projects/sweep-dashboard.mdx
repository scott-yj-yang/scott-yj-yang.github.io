## What it does

Sweep Dashboard gives one view of a mixed GPU cluster: which nodes are healthy, what is running where, and how hard each GPU is working. It connects to nodes over SSH, so nothing needs to be installed on the compute nodes.

## Key features

- Real-time cluster overview with node health, GPU utilization, and running jobs
- Per-node GPU monitoring (utilization, VRAM, temperature) via `nvidia-smi`
- Remote log viewer with auto-refresh
- Job dispatch: upload and launch sweep scripts on any node
- Browser-based SSH terminal for quick node access
- Add, remove, and configure nodes from the web UI, with encrypted password storage
